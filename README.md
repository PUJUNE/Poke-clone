# 포켓몬 클론 — 1세대 151마리 · 관동지방

포켓몬스터 1세대(레드/블루)를 본뜬 브라우저 게임. 외부 라이브러리 없이 HTML5 Canvas와 순수 JavaScript로 구성했고, 151종의 능력치·타입·포획률·레벨업 기술·진화 조건은 PokéAPI에서 수집한 실제 게임 데이터를 사용함. 몬스터 그래픽은 PokéAPI 공식 스프라이트(정면·후면, 96×96)를 로컬 `sprites/` 폴더에서 불러와 그리고, 맵 타일은 절차 생성으로 그림.

## 실행 방법

`index.html`을 브라우저(Chrome/Edge)에서 열면 바로 시작됨.

## 조작법

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| Z / Space | 조사·대화·전설 포켓몬 깨우기 |
| Enter / X / Esc | 메뉴 (포켓몬·가방·도감·박스·저장) |

## 게임 요소

- **151종 실데이터** — 종족값(HP/공격/방어/특수/스피드), 타입, 포획률(0~255), 경험치 배당, 레드/블루 레벨업 기술표를 그대로 반영. 캐이시나 메타몽처럼 공격기가 없는 종은 원작처럼 발버둥으로 싸움
- **진화** — 레벨 진화(이상해씨 16 등), 진화의 돌 5종(불꽃·물·천둥·잎·달, 맵 곳곳에서 입수), 통신교환 진화(고우스트·윤겔라 등)는 레벨 37 진화로 대체. 이브이는 돌에 따라 3종으로 분기
- **전투** — 15타입 상성표, 물리/특수 분리, 자속 보정, 급소, 명중률, 랭크 변화(울음소리·꼬리흔들기 등), 상태이상(잠듦·마비·독·화상·얼음), 연속기·반동기·흡수기·자폭·고정 데미지 기술까지 구현
- **관동 지도 (원작 배치)** — 384×400타일 월드를 카메라 스크롤로 탐험. 도시 11곳·도로 25개의 위치·크기를 원작 맵 크기·연결 오프셋 수치 그대로 재현(오버월드 면적 원작 대비 100%). 상록숲·달맞이산·바위산터널·무인발전소·챔피언로드·쌍둥이섬·블루시티동굴·사파리존을 던전 존으로 인라인해 전체 보행 면적은 원작 대비 약 90.5%. 달맞이산·바위산터널·상록숲·챔피언로드는 원작처럼 통과하지 않으면 다음 지역으로 갈 수 없음
- **체육관 8곳 + 포켓몬리그** — 웅(회색)→이슬(블루)→마티스(갈색)→민화(무지개)→독수(연분홍)→초련(노랑)→강연(홍련)→비주기(상록, 배지 7개 필요) 관장의 파티는 원작 레벨·구성 그대로. 배지 8개를 모으면 석영고원에서 사천왕 4연전 + 챔피언 라이벌전(스타터에 따라 에이스가 달라짐)
- **NPC 52명** — 마을 주민의 힌트, 길을 막는 검문 경비(노랑시티 배지 3개·사이클링로드 4개·19번수로 5개·리그 관문 8개), 도로의 일반 트레이너 10여 명, 잠만보 2마리(12·16번도로, 포켓몬피리 필요), 교환 대신 선물로 주는 희귀 포켓몬(마임맨·루주라·파오리·내루미·이브이·라프라스·시라소몬/홍수몬 택1), 잉어킹·폴리곤 판매원, 화석 부활(암나이트/투구 택1 + 프테라)
- **퀘스트** — 오박사의 소포 심부름(상록시티 프렌들리숍), 후지노인의 포켓몬피리, 챔피언 등극 후 블루시티동굴 개방
- **지역별 야생 포켓몬 (원작 출현표)** — 도로·던전별 출현 종·레벨·확률을 원작 인카운터 테이블에서 변환해 적용. 수로는 왕눈해, 보라타운 묘지에는 고오스, 사파리존에는 켄타로스·럭키·스라크·미니룡
- **전설 포켓몬 5마리** — 프리져(쌍둥이섬)·썬더(무인발전소)·파이어(챔피언로드)·뮤츠(블루시티동굴, 챔피언 후)·뮤(숨겨진 곶)가 잠들어 있음. 말을 걸어 깨우면 1회성 전투
- **포획·도감** — 포획률은 실수치 기반(HP가 적고 상태이상일수록 상승). 도감에서 본 포켓몬(○)과 잡은 포켓몬(●) 151종 진척을 확인
- **상점·돈** — 야생전 승리로 상금을 벌어 각 도시 프렌들리숍에서 몬스터볼·상처약 구매. 파티 6마리 초과분은 박스로 가며 박스↔파티 교체 가능
- **회복·저장** — 포켓몬센터(십자 건물 문)를 밟으면 전원 회복 + 부활 지점 갱신. 메뉴의 저장으로 localStorage에 기록

## 파일 구성

- `index.html` — 진입점
- `style.css` — 화면 배치
- `pokedex.js` — 151종 + 기술 122개 데이터 (자동 생성)
- `sprites/front/`, `sprites/back/` — 151종 정면·후면 스프라이트 PNG (PokéAPI sprites 저장소)
- `map.js` — 관동 월드맵 빌더 (원작 좌표 존 44개·연결 개통·관장/사천왕 데이터·NPC 52명 배치)
- `game.js` — 게임 엔진 (전투·트레이너전·배지·퀘스트·진화·도감·상점·세이브·렌더링)
- `tools/build_pokedex.mjs` — PokéAPI 수집 스크립트 (`node tools/build_pokedex.mjs`로 재생성)
- `tools/build_kanto_layout.mjs` — 원작 맵 크기·연결 데이터 → 절대좌표 산출·검증
- `tools/build_kanto_wild.mjs` — 원작 야생 출현표 → 게임 풀 변환
- `tools/smoke_test.js` — 헤드리스 검증 53항목 (`node tools/smoke_test.js`)

## 세이브 호환

구버전(이전 맵) 세이브는 이어하기 시 자동 마이그레이션됨 — 파티·박스·가방·소지금·도감은 그대로 보존되고, 위치만 태초마을에서 다시 시작함.
